# 사내 IT 헬프데스크 안내

## 와이파이 연결 문제

3층 회의실은 AP가 천장에 있습니다. 목록에 뜨는데 연결이 안 되면
노트북의 저장된 네트워크를 삭제하고 다시 연결해 보세요.
그래도 안 되면 IT 담당자에게 AP 재시작을 요청하세요.

## 인터넷 접속 문제

연결은 되는데 인터넷이 안 되는 경우는 DNS 문제일 수 있습니다.
명령 프롬프트에서 ipconfig /flushdns 를 실행해 보세요.
같은 층 핸드폰이 되면 노트북 개별 문제입니다.

## VPN 인증 문제

VPN 클라이언트를 최신 버전으로 업데이트하세요.
사번과 비밀번호를 확인하세요. 비밀번호에 특수문자가 있으면 변경 후 시도하세요.
'인증 실패'가 계속되면 계정 잠금 여부를 확인하세요.

## VPN 연결 후 사내망 문제

VPN은 되는데 파일서버가 안 보이면 사내 DNS가 안 먹는 경우입니다.
파일서버는 IP(\\10.0.1.20)로 직접 접속해 보세요.

## 인쇄 불가 문제

2층 공용 프린터 용지 걸림이 잦습니다. 용지를 절반만 채우세요.
인쇄가 안 되면 대기열에 쌓인 문서를 지우고 다시 시도하세요.

## 출력 품질 문제

글자가 깨지면 드라이버를 이전 버전으로 롤백하세요.
엑셀 대용량(20MB 이상)은 PDF로 변환 후 인쇄하세요.
